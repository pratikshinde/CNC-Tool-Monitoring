CNC Tool Monitor

System

Acknowledging records that an alarm was seen. A latch only releases once the condition itself has cleared.

Trends

Sampled once a second and held in RAM only — the history resets on reboot. Long-term logging is not implemented; log from Modbus (see the Comms tab) if you need durable history.

Cut detection

Thresholds are only evaluated while the spindle is cutting. These decide when that is.

Cut-detect must exceed idle by at least 20%, or the state machine chatters between idle and cutting.

Current (CT)

Zero

With the spindle stopped, re-measure the CT's DC bias. The SMU applies this locally; the ESP32's own copy is refreshed on the next config save.

Span

Run a known load, read it with a clamp meter, and enter that value. Current passes through zero, so one point is enough.

Values

The cutoff reports exactly zero below its value. An RMS of noise is never zero, so without it an idle spindle reads a small phantom current.

Pressure

Two-point calibration

Apply a pressure, read the reference instrument, enter it, capture. Repeat at a different pressure, then apply. Two points are needed: the 4 mA live zero makes the error a slope and an offset, and one point cannot solve both.

Values

Speed (RPM)

The hardware filter caps at about 12 µs. Larger values are clamped, and anything near a millisecond would cap measurable speed far below the spindle's range.

Spindle

Each SMU owns its own acquisition, alarm evaluation and PLC outputs — this device stays correct even while a link below reads stale or down. Age, CRC and timeout counts are since the ESP32 last booted, not lifetime figures.

Connectivity

WiFi

The fallback access point stays up regardless, so a wrong password here can never lock you out of this page.

Modbus

RTU (RS485)
TCP

Both RTU and TCP are always available at once — see MODBUS_REGISTER_MAP.md for the full register layout, including the per-SMU link-health block this UI's SMU status tab also shows.

Firmware

Firmware update

Upload a .bin built for this project. It is written to the spare slot; the running firmware is untouched until it verifies and reboots. If the new build fails to run, the bootloader reverts automatically.

Maintenance

Factory reset restores every setting, including calibration and comms, then restarts. It does not touch either SMU's own local calibration copy.
